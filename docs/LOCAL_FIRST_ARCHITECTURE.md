# Архитектурное решение: local-first

**Статус:** обязательное ограничение для последующих изменений основного приложения.

## Основное назначение

Content Factory — локальное приложение для одного владельца. FastAPI обслуживает локальную админ-панель и локальный API; это внутренний интерфейс приложения, а не публичный веб-сервис.

## Что не входит в архитектуру

Без отдельного явного требования владельца не добавлять в основное приложение:
- серверную авторизацию или аккаунты пользователей админ-панели;
- развёртывание API как публичного или удалённо администрируемого сервиса;
- серверное хранение настроек, токенов, базы данных или очереди публикаций;
- защитные ограничения, основанные только на предположении, что панель будет открыта в интернете.

Поэтому наличие технической возможности указать другой адрес привязки само по себе не является требованием к проекту и не оправдывает добавление серверной архитектуры.

## Допустимые сетевые интеграции

Сохраняются нужные приложению интеграции с Telegram, выбранным AI endpoint и настроенным пользователем прокси.

Отдельно в будущем может быть добавлен сервер лицензирования для покупки, активации и проверки лицензии. Его границы должны оставаться узкими: лицензирование не должно делать локальную панель, локальные настройки или публикацию управляемыми удалённо.

## Правила разработки и проверок

1. Сначала искать подтверждённый дефект в текущем локальном сценарии.
2. Не добавлять зависимости и компоненты сервера без необходимости.
3. Проверять API через локальные тесты и подмены внешних сервисов.
4. Не выполнять реальные покупки, активацию лицензии, вход в Telegram или публикацию в каналы во время регрессионных тестов.
5. Если будущая работа потребует изменить эти границы, сначала получить отдельное явное решение владельца.
