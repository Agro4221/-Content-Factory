# Политика безопасности

## Как сообщить об уязвимости

Если вы нашли уязвимость, не открывайте публичный Issue. Напишите
владельцу репозитория в личные сообщения и опишите:

- что делает уязвимость;
- как её воспроизвести;
- каковы последствия.

Ответ ожидается в течение 7 дней. Исправление выпускается новым релизом.

## Что нельзя коммитить в репозиторий

Проект работает с учётными данными Telegram и API-ключами. В репозиторий
никогда не попадают:

- `API ID` / `API Hash` Telegram;
- токен бота;
- ключи AI-API (OpenRouter, DeepSeek, Groq и любые OpenAI-совместимые);
- логины и пароли прокси;
- файлы сессии Telethon (`*.session`);
- содержимое `.env` и базы `bot_storage.db`.

В репозитории лежит только `.env.example` — шаблон с пустыми значениями.

Проверка на посторонние секреты запускается в CI:

```powershell
python tests/check_for_secrets.py
```

Скрипт завершится с кодом `1`, если в рабочем коде найдены значения,
похожие на настоящие ключи.

## Как приложение хранит секреты

- Секреты шифруются через **Windows DPAPI** (`CryptProtectData`) и лежат
  в `bot_storage.db` в виде блобов с префиксом `dpapi:v1:`.
- Блоб дополнительно привязан к приложению дополнительной энтропией:
  расшифровать его другим приложением под тем же пользователем нельзя.
- DPAPI привязывает значение к учётной записи Windows и к этой машине.
  Скопированная на другой компьютер база секреты не выдаёт — это
  ожидаемое поведение, а не ошибка.
- В панели вместо значения показывается маска. Пустое поле при
  сохранении означает «оставить как есть», отдельная кнопка удаляет секрет.
- Секреты не попадают в журнал, в терминал и в ответы API.
- После миграции база сжимается (`VACUUM`), чтобы открытое значение
  секрета не осталось в освободившихся страницах файла.

## Панель управления

- По умолчанию панель слушает только `127.0.0.1` — из внешней сети она
  недоступна.
- Служебные скрипты (`tools/doctor.py`, `tools/smoke_test.py`,
  `tests/check_for_secrets.py`) не печатают значения секретов ни в терминал,
  ни в отчёты.

## Что проверить перед публикацией своего форка

```powershell
python tests/check_for_secrets.py
python -m pytest -q tests
python tools/doctor.py
```
