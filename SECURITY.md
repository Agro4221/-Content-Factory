# Security Policy

## Секреты

Не публикуйте Telegram API credentials, bot tokens, AI API keys, proxy credentials, session-файлы и другие секреты в Git, Issues или Pull Requests.

Используйте локальный `.env` или другой внешний механизм хранения секретов.

## Локальный запуск

FastAPI-панель рассчитана прежде всего на локальное использование. Не выставляйте административный интерфейс напрямую в интернет без дополнительной защиты.

## Сообщение об уязвимостях

Не публикуйте рабочие credentials или полный exploit-код в открытом issue. Для чувствительных случаев используйте приватный канал связи с владельцем репозитория.
