# Contributing

Спасибо за интерес к проекту.

Это учебный и экспериментальный проект, поэтому небольшие исправления, улучшения документации, тестов и обработки ошибок особенно приветствуются.

## Перед Pull Request

- опишите, что именно изменилось;
- по возможности добавьте или обновите проверку для изменённого поведения;
- не добавляйте секреты, локальные базы, session-файлы и generated artifacts;
- учитывайте, что основной сценарий проекта рассчитан на локальный запуск.

Для крупных изменений лучше сначала обсудить идею в Issue.
