Ключи от my.telegram.org и токен бота от @BotFather. Без них бот не запустится.

Токен от @BotFather. Бот должен быть добавлен в целевые каналы как администратор.

Источники

Каналы-доноры, откуда бот берёт посты. Указывайте @username или числовой ID.

Каждый канал с новой строки. Бот должен иметь доступ на чтение.

Нет источников

Бот не знает, откуда брать посты. Укажите @username канала или числовой ID — каждый с новой строки.

Категории и каналы для постинга

Тема, которую выберет ИИ, сопоставляется с целевым каналом. Минимум одна пара «тема → канал» обязательна.

Если ИИ не находит подходящую тему, используется общее — заведите такую пару, чтобы посты не терялись.

Нет сопоставлений

Создайте пары «тема → канал». Если ИИ не находит тему, используется общее — без пары посты будут пропускаться.

Фильтры и оформление

Что бот пропускает и как подписывает опубликованные посты.

Чем меньше, тем чаще опрос — но выше риск FloodWait. 60 сек — безопасный дефолт.
Добавляется в конец каждого поста. Можно оставить пустым.
Посты с этими словами будут пропущены. Каждое с новой строки. Минимум 3 символа в слове.
Задержка применяется сразу, остальное — на следующем круге.

Telegram
ERR-201 — Telegram API не принимает данные

Проверьте API ID и API Hash на my.telegram.org. Введите их без пробелов.

ERR-202 — Неверный токен бота

Создайте или обновите токен через @BotFather. Бот должен быть администратором целевого канала с правом публикации.

ERR-203 — Telegram-сессия не работает

Остановите приложение, проверьте файл сессии и авторизацию Telegram, затем запустите снова. Не удаляйте файл сессии, если не уверены, что он не нужен.

ERR-204 — FloodWait

Telegram временно ограничил запросы. Обычно ничего делать не нужно: парсер ждёт и повторяет попытку позже.

ERR-205 — Бот не может публиковать

Добавьте бота в целевой канал и выдайте право публикации сообщений.

Сеть
ERR-301 — Прокси недоступен

Проверьте хост, порт и доступность сервера. На странице «Сеть» используйте проверку соединения перед сохранением.

ERR-302 — Неверные учётные данные прокси

Проверьте имя пользователя и пароль. Для прокси без авторизации оставьте поля пустыми.

AI
ERR-401 — Локальный AI недоступен

Запустите Ollama или LM Studio и убедитесь, что нужная модель установлена и доступна.

ERR-402 — Модель не найдена

Обновите список моделей в настройках AI. Если модель не отображается, загрузите её в выбранном локальном провайдере.

ERR-403 — Облачный AI недоступен

Проверьте адрес API, ключ, выбранную модель и баланс у провайдера.

Ничего не найдено по запросу «».
